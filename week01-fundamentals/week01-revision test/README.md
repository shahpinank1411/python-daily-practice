# Week 1 Revision Test

Cumulative test covering: variables, data types, type casting, operators,
control flow, logical operators, for/while loops, break/continue, nested loops.

## Format
- Part A: 5 timed coding problems
- Part B: 3 code-tracing/explanation questions
- Part C: 1 synthesis problem combining multiple concepts

## Result
All problems solved correctly (with review/correction rounds on a few).
Key learning: always re-verify reused logic (e.g. leap year conditions)
rather than assuming it's still complete.
